## 1. Proposed solution

A custom PHP + MySQL website with a Bootstrap 5 frontend and a protected admin panel. A custom stack (rather than WordPress) is recommended because the client needs a small number of focused features, strong control over security, and zero plugin maintenance for non-technical staff.
